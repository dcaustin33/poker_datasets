# Poker Datasets

Processes poker hand history data into training datasets.

## Setup

1. Download Pluribus dataset from https://github.com/uoftcprg/phh-dataset
2. Download PokerBench CSV files from https://huggingface.co/datasets/RZ412/PokerBench
3. Run `create_datasets.py` to generate processed datasets

## Usage
Fill in relevant fields within create_datasets (sorry no argparsing here).
```bash
python create_datasets.py
```
